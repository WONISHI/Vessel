# Offline OCR assets

Engine: @oovz/esearch-ocr 8.4.4 (Apache-2.0).
Models and Chinese/English dictionary: PaddleOCR v4, from upstream eSearch-OCR's ch.zip release:
https://github.com/xushengfeng/eSearch-OCR/releases/tag/4.0.0
Archive: https://github.com/xushengfeng/eSearch-OCR/releases/download/4.0.0/ch.zip
PaddleOCR project: https://github.com/PaddlePaddle/PaddleOCR (Apache-2.0).

These assets are bundled; recognition does not download models or upload images.
The build copies the installed onnxruntime-web WASM runtime into runtime/.
