Vessel - 现代化笔记应用

简洁、高效、跨平台的知识管理工具

为什么选择 Vessel？

Vessel 是一款专为开发者和知识工作者设计的现代化笔记应用。基于 Electron + React + TypeScript 构建，支持 Windows、macOS 和 Linux 平台。内置 Markdown 编辑器、SQLite 本地存储、文件树管理等功能，让你的知识管理更加高效。

本地优先

所有数据存储在本地 SQLite 数据库中，无需联网即可使用，保护你的隐私安全。

Markdown 编辑

内置功能完善的 Markdown 编辑器，支持实时预览、语法高亮、数学公式等。

开发者工具

内置调试面板，可查看控制台日志、性能监控、系统信息、数据库内容等。

快速开始

下载安装后，打开应用选择或创建工作区，即可开始记录你的想法和知识。支持文件夹管理、标签分类、全文搜索等功能，帮助你快速组织和检索内容。

Vessel 还支持内嵌浏览器功能，可以在应用内直接访问网页，方便你在记录笔记的同时查阅资料。支持多标签页、书签管理、开发者工具等浏览器常用功能。
