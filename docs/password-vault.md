# 本地密码保险库（第一版）

入口：活动栏浏览器地址栏右侧的钥匙按钮。

## 使用

1. 首次打开设置至少 12 字符的主密码并确认。没有找回主密码或开发者解密入口。
2. HTTPS 登录表单提交或离开已填写的账号密码输入框后，Vessel 自动询问是否保存；若保险库尚未创建或被锁定，先创建/解锁，再确认保存。不会在每次输入时弹窗。
3. 可选择“此次不保存”或“此网站永不保存”。候选密码只在内存中保留最多 60 秒。
4. 再次访问同一来源，在钥匙面板选择账号，点击“填充当前网页”。不会自动提交登录。
5. 支持多账号、删除（公共确认弹窗）、立即锁定、5 分钟闲置锁定、系统锁屏/休眠/退出锁定。
6. 在“加密导出备份”中重新输入主密码，设置不同的独立导出口令。导入需要当前主密码和备份口令，同来源同账号不会覆盖现有记录。

第一版只处理顶层 HTTPS 页面中的标准 form：一个可见的当前密码输入框，搭配 username/email/text 账号框。拒绝 HTTP（包括 localhost）、跨域 iframe、跨域 form action、多密码框及 new-password 注册/改密表单。没有标准 form 的自绘控件或分步登录站点可能需要后续适配。

## 存储与加密

- userData/password-vault/vault.json，与工作区目录分离。没有接入工作区同步。
- AES-256-GCM，随机 256 位保险库密钥，每次加密新生成 96 位 nonce，128 位认证标签；以格式版本及记录 ID 作为 AAD。
- 网站 origin、账号、密码及修改时间一起加密；永不保存的网站列表同样加密。
- Argon2id：64 MiB，3 次迭代，p=1，256 位输出，128 位随机盐。主密码派生密钥先包裹保险库密钥，再经 safeStorage 加密。只存这一份双层密钥包，不保留绕过主密码的副本。
- safeStorage 不可用或 Linux 降级为 basic_text 时拒绝创建、解锁和保存。
- 原子替换数据文件，目录权限 0700，文件权限 0600（Windows 仍依赖系统 ACL）。
- 导出使用独立口令派生的密钥加密，不依赖原设备钥匙串，因此可在另一设备新建保险库后导入。

## 信任边界

主进程管理密钥及密码；管理 UI 不接收网站密码，列表只含账号元数据。所有保险库管理 IPC 验证发送 frame 是受信任主窗口的主 frame。guest 只能报告当前主 frame 的登录表单，不提供网页可调用的读取/解密 API。填充前验证 guest 属于调用窗口、仍存活且协议/域名/端口与记录完全一致。网页 preload 再次验证来源、表单 action、可见字段，不自动提交。

主窗口已关闭 nodeIntegration。保留现有 contextIsolation，并保持浏览器 guest 的 sandbox、webSecurity 及禁用 nodeIntegration。

保证范围是离线密文保护，不是“任何攻击者绝对无法解密”：已解锁系统中的恶意软件、调试/内存转储、被攻陷的应用或目标网页均可能获取使用中的明文。自动填充必须向目标网页提供密码，网页脚本可以读取已填充字段。JS 字符串也无法保证完全从内存擦除；锁定会清零密钥 Buffer 并释放候选记录，但不承诺消除所有历史内存副本。macOS 正式安装包需要稳定的代码签名，以确保钥匙串行为一致。

测试使用临时目录及模拟系统密钥存储，不使用真实账号。跨平台原生钥匙串、签名安装包及真实网站端到端行为仍需验证。

## 账号和密码管理与查看密码

浏览器更多菜单的“账号和密码”打开已有保险库。解锁后显示网站来源、账号和默认遮蔽的密码，列表接口不返回密码。

每次点击“查看密码”，主进程单独调用 macOS LocalAuthentication 的 `deviceOwnerAuthentication`。系统可提供 Touch ID、Apple Watch 或当前用户登录密码，Vessel 不接收、不存储系统密码。取消、验证失败、锁屏或保险库被锁定时拒绝返回网页密码。验证成功只返回选中的一条密码；界面 15 秒后、关闭弹窗或窗口失焦时清除显示。

原有主密码仍用于解锁加密数据；系统验证是查看明文前的额外验证，不取代主密码。当前查看密码功能支持 macOS，其他系统不回退为无验证显示。

`native/vessel-auth.m` 在 macOS 构建时用 Xcode Command Line Tools 编译为 arm64/x86_64 通用原生助手，输出到 `out/main/vessel-auth`。打包配置将助手从 asar 解包供运行，用户机器无需编译工具。


### 全部网站账号列表

“账号和密码”入口直接打开全部网站的管理列表，支持按网站域名或账号搜索，展示网站 favicon（失败时显示通用图标）、域名、账号和固定长度的密码遮罩。没有记录时显示空状态；创建保险库和导入导出操作位于“保险库设置”。

为了在保险库锁定时仍展示列表，文件增加可选 `catalog`：仅包含 id、网站、账号和更新时间，并由系统 `safeStorage` 加密，不含密码。密码仍保留原来的主密码与系统加密保护。旧文件首次解锁后生成目录，不改变原有密码加密方式。需要查看密码时，受主密码保护的保险库必须先解锁，再通过系统身份验证。

### 当前网站密码面板与管理 Sheet

地址栏钥匙仅在当前 HTTPS 来源（包括端口）有已保存记录时出现。点击钥匙显示本站账号，选中账号通过身份验证后展示详情，可复制账号、查看/隐藏或复制已显示的密码。“管理密码”打开右侧“账号和密码”Sheet，列表仍覆盖所有网站，蒙层避开活动栏和底部状态栏。

主密码加密方式不变：保险库锁定时先在面板解锁，然后进行系统身份验证。切换网页会关闭本站面板并清除已显示的密码；15 秒自动隐藏和失焦隐藏保持有效。
